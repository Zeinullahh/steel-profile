# Пакет материалов для создания сайта STEEL PROFILES

## Что отправить кодинговому агенту

Отправьте весь ZIP целиком и сообщение:

> Реализуй полностью сайт STEEL PROFILES на Next.js по файлу `ТЕХНИЧЕСКОЕ_ЗАДАНИЕ.md`. Это **реальная задача по разработке**, не генерация статичной картинки. Используй `CONTENT_DATA.json` как основу локального каталога, сверь факты с указаниями в ТЗ; фотографии уже готовы в `public/images`. Взять сгенерированные изображения из `design-reference/` только как стилевые UI-референсы. Без базы данных, CMS, API, онлайн-оплаты и серверной формы. Все страницы должны быть на русском языке, дизайн — аккуратный glassmorphism. Сначала запусти сборку, затем проверь все 19 маршрутов карточек, mobile и desktop, после чего подготовь к Vercel и дай README. Не придумывай контакты, цены или завершённые объекты.

## Файлы

- `ТЕХНИЧЕСКОЕ_ЗАДАНИЕ.md`: развёрнутые требования, страницы, SEO, UI, тестирование и план.
- `CONTENT_DATA.json`: первичная структурированная локальная база ассортимента (19 направлений, 5 групп, контакты).
- `ASSET_MANIFEST.json`: подтверждение источника каждой фотографии и путь к ней.
- `public/images/`: 22 WebP-изображения и PNG логотипа; **это папка для готового Next.js-проекта**.
- `source-images/`: оригинальные изображения, извлечённые напрямую из PDF без AI-изменений.
- `design-reference/`: 2 генерированных UI-концепта (ориентир по дизайну, не источник характеристик).

## Важные замечания

В исходном PDF текст преобразован в векторные кривые, поэтому основные данные переписаны визуально. Некоторые характеристики, изображения и контакты нуждаются в ручной сверке с оригиналом перед публикацией. В пакете специально нет маркетингово выдуманных цен, логистики и истории бренда. Изображения товаров берутся из реального PDF, а не синтезируются нейросетью.
